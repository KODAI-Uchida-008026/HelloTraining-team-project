## プロジェクト概要 <a id="project-overview"></a>

| 項目 | 内容 |
|------|------|
| **ゲームタイトル** | FindTheCat 『猫を探そう！』 |
| **一言で説明すると** | 2Dアクションゲーム |
| **ゲームの目的** | 猫を探してゴールを目指す　ゴールに向けて「ヒントを探す」 |
| **プレイヤー操作** | ↑ ↓ → ← とWASDで移動、スペースでジャンプ　Gキーを押してみると... |
| **勝利条件** | 猫を探してゴールにたどり着く |
| **失敗条件** | 3回落下するとゲームオーバー |
| **特徴・工夫点** | 『Climb Cloud』を参考としてシーン遷移やコース形態、プレイヤーやゴール設定を工夫 |

## 開発ルール <a id="development-rules"></a>

- **Git運用**  
  - 1〜2時間ごとにCommit  
  - 1日2〜3回Push  
  - 作業前に必ず「Pull」して最新を取得  
  - コンフリクトが起きた場合はリーダーが調整  

- **Unityプロジェクト設定**  
  - Unity 6（URP）を使用  
  - 各自、同バージョンを統一  
  - 不要アセットは追加しない（軽量管理）  

- **フォルダ構成推奨**
```
Assets/
├─ FindTheCat
  ├─ Fonts
├─ Folder
  ├─ Prefabs/
├─ Scenes/
├─ Settings
├─ TextMesh Pro
└─ プログラム
```

## プロジェクト概要 <a id="project-overview"></a>

| 項目 | 内容 |
|------|------|
| **ゲームタイトル** | FindTheCat 『猫を探そう！』 |
| **ゲーム形式** | 固定スクリーン型横視点フリップスクリーン方式2Dジャンピングアクションゲーム |
| **ゲームの目的** | 猫を「探して」ヒントを「探して」ゴールを目指す |
| **プレイヤー操作** | → ← とD Aで移動、スペースでジャンプ　Gキーで重力反転　Bで加速 |
| **勝利条件** | 猫を探してゴールにたどり着く |
| **失敗条件** | 3回落下するとゲームオーバー |
| **特徴・工夫点** | 『Climb Cloud』を参考としてシーン遷移やコース形態、プレイヤーやゴール設定を工夫 |

## 工夫したポイント <a id="highlights"></a>

**工夫①：Climb Cloudからの発展**<br>
チーム開発が始まるに当たって、1週間のうち1日は就職支援の授業が挟まってしまい、翌週始めの午後から発表会であるため実質的には4日間しか開発期間がありませんでした。このことから企画・計画会議の時点から短期間での完成を目指す上で授業で制作したゲームを参考とし、発展させた内容とすることにしました。これにより短期間でありながら、2体のキャラクター、6つのゲームシーン、様々なギミックを実装することができました。

**工夫②：課題テーマ「探す」に沿った謎解きジャンプアクション**<br>
猫のキャラクターを増やし、それぞれがそれぞれを探して追いかけるゲーム設計としながら、2匹のステータスは大きく違うものとしました。また、足場に気を付けて右へ移動するシンプルなゲームにするのでは無く、すり抜ける足場のトラップや左へ移動すると前のシーンの始めに戻るギミック、キャラクターの上下反転機能を活用するヒントを見て画面内に映り切らない位置を使う謎解き要素などシーン遷移やコースの難易度設定に至るまでチームでしっかり話し合い設計しました。

## 苦労した点と解決策 <a id="troubles"></a>

**苦労した点：コンフリクトによる開発の遅れ**<br>
それぞれが指示通りに担当の作業を行っていながらも、ちょっとした食い違いや善意の修正、作業の遅れなどによって同一の作業内容を行ってしまうことによるコンフリクトが何度も起こってしまい開発の遅れが起こってしまった。

**解決策**<br>
これまで通り随時確認を行うことを継続しながら、小さく完成させてから徐々に大きくしていく、短期間での完成を第一とする計画へとシフトしました。全員にとってこれが初めてのチーム開発であるため、コンフリクトを完全に無くすためにチームを厳格に縛るのではなく、コンフリクトが起こったとしても完成できるチーム開発にしました。牛歩でも作業ごとに声を掛け合っていたことから、ゲーム開発自体のミスは皆無に等しく、コンフリクトも徐々に減っていきました。

## 今後の改善点 <a id="future"></a>
それぞれが能力の違う人間であり、短期間での意見のすり合わせも決して簡単では無かったため、幾度となくコンフリクトが起こり、作業内容の食い違いが起こりました。しかし、これらは実際のIT現場における開発作業でも起こり得ることであり、転職に向けた大きな経験値であると考えられることから、それぞれがそれぞれの反省点を振り返り今後に活かしていき、更なる発展に努めて参ります。
